# Demo

*Everything here is invented. "Ledgerline" is a fictional records-retention vendor and "Marlowe Freight" a fictional customer.*

## The input

Run `renewal-risk` on this, exactly as a busy CSM would type it:

> Marlowe Freight, $180k ARR, renews 14 March, 60 day notice. My champion is Priya in compliance. Usage looks fine but she mentioned there's a new CFO. I haven't met them.

## What to do

1. Run the skill on that input as if the user typed it.
2. Show the output in full.
3. Then say, in one line: "That took one paragraph from you. Paste yours in the same shape and I will do the real account."

## The shape of a good result

It leads with a call (contract, not churn), puts a dollar range on it ($110k to $180k), names the new CFO as the decider the user has not met, tags each piece of evidence as said, seen or inferred, says what would make the read wrong, and ends with one play, one owner, one date and a checkpoint that can fail. If the output is longer than a page or has no dollar range, it missed.
